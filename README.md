# 多平台开播提醒

AstrBot 插件，统一监控常见直播平台，并在订阅的群聊检测到开播/关播时发送文字提醒和图卡。B 站、虎牙、斗鱼、Twitch、Kick 和 YouTube 共用图卡渲染流程；订阅按会话隔离并持久化。参考了 [B站 UP 主开播监测插件](https://github.com/BB0813/astrbot_plugin_bilibiliobs) 的群级订阅和状态轮询体验；本插件为独立实现，没有复制其代码。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

源码仓库：[PiaoL/astrbot_plugin_live_notice](https://github.com/PiaoL/astrbot_plugin_live_notice)。

## 命令

```text
/开播订阅 <平台> <房间号/用户ID/用户名> [房间号|UID]
/开播取消 <平台> <房间号/用户ID/用户名> [房间号|UID]
/开播列表 [平台]
/开播查询 <平台> <房间号/用户ID/用户名> [房间号|UID]
```

平台别名：`b站` / `bilibili`、`虎牙` / `huya`、`斗鱼` / `douyu`、`Twitch`、`Kick`、`YouTube` / `yt`。

示例：

```text
/开播订阅 虎牙 88863
/开播订阅 b站 12345  # 可填直播间号或主播 UID
/开播订阅 b站 8739477 房间号  # 明确按直播间号订阅
/开播订阅 b站 8739477 UID  # 明确按主播 UID 订阅
/开播订阅 Twitch twitchdev
/开播取消 虎牙 88863
/开播列表
/开播查询 YouTube UCxxxxxxxxxxxxxxxx
```

添加和取消订阅需要 AstrBot 管理员权限；列表和即时查询可供群员使用。也可将支持的平台房间链接作为标识传入。

## 平台和凭据

| 平台 | 标识 | 凭据 | 接口情况 |
| --- | --- | --- | --- |
| 哔哩哔哩 | 直播间号 | 无 | 公开房间信息接口 |
| 虎牙 | 房间号 | 无 | 公开网页接口，格式可能变化 |
| 斗鱼 | 房间号 | 无 | 网页接口，属于尽力而为的兼容实现 |
| Twitch | 频道登录名 | 插件配置中的 Client ID / Client Secret | 官方 Helix API |
| Kick | 频道 slug | 插件配置中的 Client ID / Client Secret | 官方开发者 API |
| YouTube | Channel ID（UC 开头） | 插件配置中的 YouTube Data API Key | 官方 Data API；轮询会消耗配额，结果缓存 5 分钟 |

抖音、快手、小红书、视频号、淘宝直播等平台未纳入本版：目前无法为通用第三方订阅提供稳定、免授权的公开开播查询接口。抖音开放平台的部分直播数据能力已停止新申请并下线；快手文档中的直播状态能力标注为暂停接入。若平台之后开放可用接口，可按统一适配器结构继续添加。

## 行为说明

- 插件启动后按配置间隔轮询，默认 60 秒，允许范围 30–1800 秒。
- 默认只发送开播通知；首次添加会读取当前状态，避免主播已在直播时误报“刚开播”。
- 每个会话最多订阅 50 个主播；状态查询并发限制为 5。
- 查询失败会保留旧状态，不会把错误当作关播/开播。
- 数据写入 `data/plugin_data/astrbot_plugin_live_notice/subscriptions.json`。
- 有些平台使用公开网页接口，平台升级、地区网络或风控都可能影响查询可靠性。

## 配置

在 AstrBot「插件 → 多平台开播提醒 → 插件配置」中按需填写平台凭据。Twitch、Kick 和 YouTube 的凭据输入框为敏感字段；只给对应平台申请的只读 API 凭据，不要把密钥发到群聊。

## 安装

在 AstrBot 插件管理页选择“从 URL 安装”，填写本仓库地址；也可以下载本仓库的 GitHub Release 插件压缩包后从文件安装。依赖会由 AstrBot 根据 `requirements.txt` 安装。

## 开发与发布

仓库根目录就是插件目录。开发时在此目录修改代码；发布新版本时同步更新 `main.py` 装饰器、`metadata.yaml` 和本文件中的版本号，并创建对应的 `vX.Y.Z` Git 标签。

## 通知样式（1.1.3）

- 新订阅和重复订阅回执会显示已查询到的主播昵称，并把房间号/ID 放在昵称后。
- 开播通知按“主播开播啦 / 直播标题 / 直播间链接”发送，并生成浅色图卡：主播标题、头像、昵称、分区、直播间二维码和原直播封面。二维码指向直播间。
- 检测到关播后发送“主播已结束直播”及深色结束图卡，包含主播头像、昵称、标题、封面和本次检测到的直播时长。
- 图卡不包含示例图中的第三方署名或底部宣传文案。各平台可提供的头像、分区和封面字段不同；接口没返回封面时会退回普通文本通知。
- 图卡需要 `Pillow`、`qrcode` 和中文字体。插件依赖会安装前两者。Ubuntu/Docker 中如没有中文字体，请安装 `fonts-noto-cjk`，并在插件配置 `font_path` 填写 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`。

- 1.1.3：补齐 B 站、斗鱼、Twitch、Kick、YouTube 的头像字段适配；B 站头像缓存 12 小时，Kick 直播时通过直播信息补取头像。

- 1.1.4：主播头像使用真正的圆形透明裁切；开播和关播图卡会在封面下方显示直播间描述，描述为空时隐藏。

- 1.1.5：修复 B 站订阅查询中分区字段拼接与 AstrBot `filter` 名称冲突导致的 TypeError。

- 1.1.6：修复 B 站 API 请求使用错误 Referer 导致的 412 查询失败。

- 1.1.7：从 B 站主播资料接口同时补取昵称和头像，修复仅能显示房间号的情况。

- 1.1.8：开播和关播通知标题统一显示主播昵称，并在其后标明平台及房间号/用户 ID。

- 1.1.9：B 站订阅同时支持直播间号和主播 UID；使用 UID 订阅时，通知中展示解析到的真实房间号。

- 1.2.0：B 站文字通知同时显示房间号与 UID；订阅、取消、列表、查询、开播和关播文字均展示平台标识。

- 1.3.0：B 站数字同时匹配不同房间号和 UID 时会先提示两种主播，不自动创建订阅；可用“房间号”或“UID”参数明确选择，取消和查询命令也支持该参数。所有平台均使用对应来源页请求封面，以生成开播和关播图卡。
